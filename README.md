# guhilling/.github

Account-wide defaults for guhilling's repositories. GitHub uses the community health files kept
here, such as the issue forms under `.github/ISSUE_TEMPLATE/`, for every repository of the
account that does not have its own.

A repository that keeps any valid file in its own `.github/ISSUE_TEMPLATE/`, `config.yml`
included, gets none of the issue forms from here.

The story and epic forms label their issues `story` and `epic`. GitHub applies a label only
where it exists, so both labels are kept here and in every repository that uses the forms.
